

\# Comandos útiles de ASIR



Este archivo recoge algunos comandos básicos que pueden resultar útiles en la administración de sistemas.



\## Windows



\- `ipconfig`: muestra la configuración de red.

\- `hostname`: muestra el nombre del equipo.

\- `systeminfo`: muestra información del sistema.



\## Linux



\- `ip a`: muestra las interfaces de red.

\- `df -h`: muestra el espacio disponible en los discos.

\- `lsblk`: muestra los dispositivos de almacenamiento.
